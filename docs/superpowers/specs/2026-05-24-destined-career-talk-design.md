# 天选事业 · 通用技巧分享 — 演讲网页设计

**日期**：2026-05-24（明天上台：2026-05-25）
**目的**：为分享会"如何快速寻找到自己的天选事业"生成一个网页，承载两种使用场景：现场投影主讲 + 会后分享给听众阅读。
**交付物**：单文件 HTML（`index.html`），双击即可在浏览器打开，无构建步骤、无外部依赖（KaTeX 内嵌）。

---

## 1. 使用场景与目标

| 场景 | 怎么用 |
|---|---|
| 现场宣讲（20–30 分钟） | 浏览器打开 `index.html` → F11 全屏 → 点右下角"▶ 演讲者" → 方向键翻 8 节 |
| 会后分享 | 把 `index.html` 文件发出去（或 Cloudflare Pages 等托管），听众打开默认进入"阅读模式"，可自行点击展开细节、滚动阅读 |
| PDF 兜底 | cmd+P → 浏览器打印，自动展开所有折叠内容，输出完整 PDF |

**听众**：公开场 / 陌生人群体。语言通用，避免内行黑话；保留大纲原有的口语化比喻（"硬件 / App / 拼图 / 渣男套路"等），但确保第一次出现的术语有解释。

---

## 2. 技术形态

- **单文件 HTML**：`index.html` 一份文件包含所有 HTML / CSS / JS / KaTeX 资源
- **零依赖**：不用任何打包工具、不用 npm、不需要构建。直接双击或本地服务器打开
- **KaTeX 内嵌**：把 KaTeX 0.16.x 的 CSS + JS 直接内嵌到 `<style>` 和 `<script>` 标签里（约 70KB），保证断网/弱网可用
- **字体**：仅用系统字体栈，不引外部 webfont，确保打开秒开

**文件结构**：

```
/Users/apple/talks/destined-career/
├── index.html              # 唯一交付物
├── docs/superpowers/specs/ # 本设计文档
└── .superpowers/           # 视觉伴侣草稿（gitignored）
```

**最终体积目标**：< 300KB（含内嵌 KaTeX）。

整个网页按大纲切成 **8 个 section**，每个 section 即"演讲者模式"的一页。

| # | Section | 内容要点 | 演讲时长 |
|---|---|---|---|
| 00 | 封面 | 标题 + 副标 + "↓ 开始" 提示 | 30s |

| 02 | 心理学重构 | 自我决定论：热爱 = 自主感 + 胜任感 + 归属感 | 3min |
| 03 | 认知科学重构 | 盖洛普：天赋 × 投入 = 优势；演化核心模型；增强回路 | 4min |
| 04 | 拼图一 · 天赋 | 4.1 荣格八维（2×4 网格 + 全景互动名场面 tab）；4.2 盖洛普 34（4 栏 chip） | 7min |

## 4. 两种模式

### 4.1 阅读模式（默认）

- 连续滚动，所有 section 顺序展开
- 默认进入页面时所处的模式
- 刷新页面 / 别人打开链接 → 都是阅读模式
- 模式状态不持久化（不存 localStorage、不写 URL hash）

### 4.2 演讲者模式

**进入方式**：右下角浮动按钮"▶ 演讲者" 或按 `P` 键

**生效机制**：给 `<body>` 加 `.presenter` class，CSS 触发：

- `scroll-snap-type: y mandatory` 整个文档
- 每个 `<section>` 设 `scroll-snap-align: start` 和 `min-height: 100vh`
- 内容垂直居中，字号整体放大 1.4×
- 右下角浮"3 / 8" 指示器

**键盘导航**：

| 按键 | 行为 |
|---|---|
| → / ↓ / PgDn / Space | 下一节 |
| ← / ↑ / PgUp | 上一节 |
| Home | 跳到封面 |
| End | 跳到收尾 |
| Esc | 退出演讲者模式 |
| P | 切换模式 |

**视觉指示器**：右下角 `3 / 8` 小标，靛蓝文字，半透明白底。

## 5. 交互与动画

### 5.1 点击展开 — 荣格八维（段 04.1）

**默认布局**：2×4 网格，每格显示功能符号（Se/Si/Ne/Ni/Te/Ti/Fe/Fi）+ 中文名 + 一句话本质 + `▽` 标记

**点击行为**：
- 点任一格 → 该格原地展开，下方追加显示"一秒识别" + 名场面例子
- 同时其他已展开的自动收起（accordion 模式）
- 再点同一格 → 收起
- 高度变化用 CSS transition `max-height` ease-out 250ms

**全景互动名场面（独立子块）**：在 8 维网格下方单独一块，标题"🎭 全景互动名场面：女朋友微信发来'我感冒了，好难受'"

- 横向 8 个 chip：Se 抓取 / Si 抓取 / Ne 抓取 / Ni 抓取 / Te 决策 / Ti 决策 / Fe 决策 / Fi 决策
- 默认选中第一个（Se 抓取），下方显示对应的内心戏内容
- 点其他 chip 切换显示
- 用纯 CSS `:has()` 或简短 JS 实现 tab 切换

### 5.2 点击展开 — 盖洛普 34（段 04.2）

**布局**：4 栏纵向排列（执行力 / 影响力 / 关系建立 / 战略思维），共 33 项才干，严格按大纲提供的列表与分组实现

| 领域 | chip 数 | 才干 |
|---|---|---|
| 执行力 | 9 | 成就 / 统筹 / 信仰 / 公平 / 审慎 / 纪律 / 专注 / 责任 / 排难 |
| 影响力 | 8 | 行动 / 统率 / 沟通 / 竞争 / 追求 / 自信 / 取悦 / 体谅 |
| 关系建立 | 8 | 适应 / 关联 / 发展 / 和谐 / 包容 / 个别 / 积极 / 交往 |
| 战略思维 | 8 | 分析 / 前瞻 / 理念 / 搜集 / 思维 / 学习 / 历史 / 战略 |

**每栏**：
- 标题行：领域名 + 一句"解决什么问题"
- chip 行：该领域的全部才干名 chip
- 详情区：默认空，点击 chip 在此显示该才干的"一句话核心天赋表现"

**交互**：点 chip → 该栏底部展开/更新详情卡片；再点同一 chip 收起；点不同 chip 切换内容。

### 5.3 入场动画

**实现**：单个 IntersectionObserver 观察所有 section

- 进入视口（threshold 0.15）→ 给 section 加 `.in-view` 类
- CSS：`opacity 0 → 1` + `translateY(20px) → 0`，时长 500ms ease-out
- 触发一次后不再重置
- **演讲者模式翻页**：手动重置 `.in-view`，每次翻页都重新触发一次，做出"切换到新一页"的仪式感

**克制原则**：
- 不做弹跳、旋转、3D 翻转、视差
- 公式不做逐字打字特效
- `@media (prefers-reduced-motion: reduce)` 完全关闭所有动画

### 5.4 公式渲染

- KaTeX inline 渲染，页面加载时一次性处理所有 `$...$` 包裹的 LaTeX
- 大纲里的所有公式（刺猬理论原版、自我决定论、盖洛普方程、演化核心模型）都用 KaTeX 渲染
- **核心公式（段 03 `天选事业 = 天赋 × 兴趣 × 变现`）**：在 callout 内额外放大，"天赋 × 兴趣 × 变现"三个词用朱砂红强调

## 6. 视觉系统

### 6.1 配色

| 用途 | 色值 | 命名 |
|---|---|---|
| 主蓝（标题、链接、强调结构线） | `#1F3D7A` | 靛蓝 |
| 底色 | `#FBF9F4` | 暖白 |
| 强调红（tag、关键转折、最后阶梯） | `#C1352F` | 朱砂 |
| 次级文字 / Section 副标 | `#8A8A8A` | 中性灰 |
| 引用边线 / 阶梯竖线 | `#C8C8C8` | 浅灰 |
| 卡片细边 | `#D4D4D4` | 边线灰 |
| Callout 浅底（公式 / 重要结论背景） | `#EFEBE2` | 暖米 |
| 5Why 最后一行底（朱砂浅调） | `#F0D8D6` | 浅朱 |

**总量控制**：红色仅用在 tag 和 emphasis；蓝色承担所有结构（标题/边线/标号）；灰色承担次级层级；其他白底深色字。

### 6.2 字体与字号

```
中文：-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif
英文 / 公式辅助：-apple-system, "SF Pro Text", "Inter", sans-serif
等宽（代码）："SF Mono", "JetBrains Mono", Consolas, monospace

阅读模式字号：
  封面大标题      52 / 64px  600
  Section 标题    32 / 40px  700  靛蓝
  Section 副标    18 / 28px  400  中性灰
  二级 H4         20 / 30px  600
  正文            16 / 28px  400
  小字 / tag      13 / 20px  500

演讲者模式：整体放大 1.4×（标题约 56px，正文约 22px）
```

### 6.3 间距节奏（8px 基线）

```
Section 之间    96px（阅读）/ 整屏（演讲者）
H4 → 正文       16px
段落之间        24px
卡片内 padding  20px × 24px
```

### 6.4 复用组件

5 个核心样式块，整页靠这些拼出来。

**Tag**：`<span class="tag">公式</span>` —— 朱砂背景 + 暖白文字 + 4px radius，2px×8px padding，11–13px 字号

**Callout（公式 / 关键结论）**：
- 暖米 `#EFEBE2` 背景
- 3px 靛蓝左边线
- 起手用 ◆ 或 📌 符号
- 用于：核心公式、章节本质结论

**Step / 5Why 阶梯**：
- 编号格式：`1Why → 2Why → ... 5Why`
- 左侧 1px 浅灰竖线串联
- 每行：编号加粗 + 内容
- 最后一行（5Why 核心本质）：朱砂浅调 `#F0D8D6` 背景高亮 + 朱砂文字

**Expandable card（荣格 / 盖洛普展开）**：
- 折叠态：白底，1px `#D4D4D4` 边，hover 时边变靛蓝
- 展开态：白底，3px 靛蓝左边线，内部展开内容用 `#FBF9F4` 更浅的底
- 高度过渡 250ms

**Quote（引用 / 出处）**：
- 2px 浅灰 `#C8C8C8` 左边线
- 斜体，中性灰文字
- 用于：吉姆·柯林斯原话、其他出处引用

### 6.5 响应式

| 断点 | 处理 |
|---|---|
| ≥ 1280px（标准桌面 / 投影） | 标准布局 |
| 768–1279px（笔记本） | 内容宽度收紧到 920px |
| < 768px（手机） | 荣格 2×4 网格 → 1×8 单列；盖洛普 4 栏 → 1 栏纵叠；演讲者模式按钮隐藏（手机上没意义） |

### 6.6 打印样式（cmd+P）

- 自动展开所有折叠内容（荣格 8 格、盖洛普 34 chip 详情、名场面 tab 改为顺序列出全部）
- 隐藏演讲者按钮、模式指示器
- 字号、间距适配 A4 纸
- 颜色保留（带 `-webkit-print-color-adjust: exact`）

   - (b) 保持"34 个"开头文案，补齐缺失的一项才干（典型为"共情/Empathy"）
   - (c) 保持现状（文案 34，列出 33），台上自己 cover 这个差距
2. **段 03 增强回路图**：大纲里那段长描述（兴趣→天赋→胜任→归属→擅长→变现）需要做成：

   - (b) 环形回路图

3. **段 05 关键词交叉碰撞示意图**：大纲里【神经科学】×【教育学】×【效率工具】 = ... 这个例子，是做成连连看式的连线图，还是只用文字 + 箭头表达？
